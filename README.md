## Deep Equality

## Equal value check

    1) Two booleans are true should be equal
    2) Two booleans are false should be equal
    3) Two same arrays
    4) Two same objects
    5) Two same numbers
    6) Two same Strings

## Unequality

    1) Different booleans


    ## Boolean
    1) One Boolean one Array
    2) One Boolean one Object
    3) One Boolean one String
    4) One Boolean one Number

    ## String
    1) One String one Array
    2) One String one Number
    3) One String one Object

    ## Arrays
    1) One Array one Object
